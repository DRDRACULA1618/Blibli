# Contribuer à BliBli

1. Créez une branche depuis `main`.
2. Conservez l’interface en français et mobile-first.
3. Ne rendez jamais public un numéro au statut `proposed`.
4. N’ajoutez pas de dépendance payante au parcours de base.
5. Exécutez `npm run check` puis `npm run build` avant une pull request.
6. Documentez toute nouvelle donnée personnelle collectée.
